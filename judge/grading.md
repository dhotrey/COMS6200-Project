# Four-level diagnosis assessment

Use these shared criteria with the selected topology/fault rubric. The scenario
rubric defines the required fault type and location. Optional supporting
observations are not a checklist, and missing them must not lower the grade.
Evaluate the final primary conclusion, accepting equivalent wording and host
identities. Do not credit rejected hypotheses, unranked alternatives or a plan
to investigate as an established diagnosis.

The scenario rubrics also describe binary success. Both Correct and Mostly
correct satisfy that binary requirement. For the four-level assessment, a
minor factual error in an additional claim earns Mostly correct even when it
does not overturn the primary diagnosis. Only penalise an error established by
the supplied rubric, not an omitted optional detail or an unverified claim.

## Correct

Correct fault type and location, with no factual errors against the rubric.

## Mostly correct

Correct fault type and location, with minor inaccuracies in nonessential details.

## Partially correct

Identifies the type or location correctly, but misses the other.

## Incorrect

Neither required finding is established; symptoms or a plan alone do not count.
